# Contributing

Small, focused improvements are welcome.

## Before opening a pull request

1. Keep the application usable without a build step.
2. Do not add assets unless their redistribution terms are documented.
3. Run `npm test` with Node.js 20 or newer.
4. Test `index.html` in at least one current desktop browser.
5. Describe visible changes and known limitations honestly.

For substantial features—rigging, morph targets, model import, or mesh
export—open an issue first so the data format and scope can be discussed.
